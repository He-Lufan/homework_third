## 排错或边界验证
- 现象：1.报错检查某一行，某字符附近；
        2.Column数量与值不对应；
        3.日期值报错。
- 原因：1.几个数据值之间少','，ORDER拼写错误等；储量为零条件判断写了'==0'；DELETE前面的SELECT没有加分号；
        2.栏目里面写了created_at但是值里没有这一项；添加临时书籍没有写出版时间；
        3.日期值格式不对，少了引号。
- 处理与复验：1.符号缺失或错误的修改；判断改为'=0'；
            2.删掉了栏目里的created_at项；在出版时间的位置写NULL；
            3.加上引号。
